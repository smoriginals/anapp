
# About

## 🌺 Flower E-Commerce Website(UI&Features)

#### 📌 Project Overiew

This project is a UI-focused e-commerce garden website developed as part of a freelancer Figma design challenge. The primary objective was to accurately translate a provided Figma design into a fully responsive, pixel-perfect web interface while maintaining clean code structure and modern frontend best practices.

The website focuses on delivering a visually engaging shopping experience for garden and plant-related products, with special attention to layout consistency, typography, spacing, and component reuse. While the project does not include full backend or payment functionality, it demonstrates strong proficiency in UI cloning, responsive design, and design-to-code execution.

This challenge helped strengthen my skills in interpreting real-world design files, building scalable UI components, and matching professional design standards commonly expected in freelance and client-based projects.

# FAQs

#### 1. What is the purpose of this project?

This project was created to demonstrate UI development skills by accurately converting a Figma design into a responsive e-commerce garden website. It focuses on layout, styling, interactions, and overall user experience rather than backend functionality.

#### 2. Is this a fully functional e-commerce application?

No. This is a frontend-focused UI clone. Features such as authentication, payments, and order processing are intentionally excluded to keep the scope aligned with the design challenge.

#### 3. Which technologies are used in this project?

The project is built using React with Vite, Context API for state management, Tailwind CSS and CSS3 for styling, and Framer Motion for animations.

#### 4. Does this project include responsive design?

Yes. The UI is fully responsive and optimized for desktop, tablet, and mobile screen sizes, following mobile-first design principles.

#### 5. Is the design original or based on a reference?

The UI is based on a provided Figma design as part of a freelance design challenge. The implementation aims to closely match the design while maintaining clean and reusable code.

#### 6. How is state managed in the application?

Global UI-related state such as cart and wishlist interactions is handled using React Context API, with persistence implemented via localStorage where applicable.

#### 7. Can this project be extended with backend features?

Yes. The structure allows for easy integration of backend services such as APIs, authentication, and payment gateways if required in the future.

#### 8. What does this project demonstrate to clients or recruiters?

It demonstrates strong design-to-code skills, attention to UI detail, component-based architecture, responsive layout implementation, and the ability to complete real-world freelance-style challenges.
